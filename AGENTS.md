# Repository instructions

## Scope

This repository is a disposable non-production fixture for an OEC asynchronous development test.

## Commands

- Run tests: `npm test`
- Start locally: `npm start`

## Change boundary

For `versioned:v1.0.0/task-filter-persistence`, changes are limited to:

- `public/`
- `test/`
- documentation corrections directly related to the task

Do not add a database, authentication, analytics, deployment configuration, or third-party runtime dependencies. Do not modify remote systems.
